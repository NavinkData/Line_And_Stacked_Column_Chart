# Line & Stacked Column Chart | Power BI

## Overview

This project demonstrates the implementation of a **Line & Stacked Column Chart in Microsoft Power BI** for multidimensional business performance analysis.

The visualization combines categorical comparison with time-based trend analysis, providing a consolidated view of performance and enabling users to examine both **individual category contributions and overall trends**.

## Analytical Capabilities

* Category-level performance analysis
* Comparative analysis using stacked columns
* Trend identification through line visualization
* Interactive filtering and slicer-based exploration
* Business performance monitoring
* Structured and interactive reporting

## Technical Stack

* **Microsoft Power BI**
* **DAX**
* **Data Modeling**
* **Data Visualization**
* **Business Intelligence**

## Business Application

Line and stacked column visualizations are particularly useful for analyzing business scenarios such as:

* Sales and revenue performance
* Product and category contribution
* Regional performance
* Profitability analysis
* Period-over-period trends
* Operational and management reporting

## Objective

The objective of this project is to demonstrate how Power BI can transform structured business data into an **interactive analytical view**, allowing users to identify patterns, compare performance, and derive meaningful insights efficiently.

## Key Takeaway

The project emphasizes the practical use of **Power BI visualization, DAX, and analytical reporting techniques** to communicate complex business information through a clear and decision-oriented dashboard.
